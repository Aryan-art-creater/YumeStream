# 🌸 YumeStream

**YumeStream** is a fan-made anime streaming website project designed and developed as a frontend web development project.

The project focuses on creating a modern anime streaming experience with a visually engaging interface, anime browsing pages, premium features, and individual anime pages.

## ✨ Features

* 🏠 Modern anime streaming homepage
* 🎬 Anime browsing and featured sections
* 🔎 Anime-focused navigation and content organization
* 📺 Individual pages for different anime titles
* ⭐ Premium section and premium membership interface
* 💬 Premium chatbot interface
* 📱 Responsive/mobile-focused styling
* 🎨 Custom UI design and animations
* 🖼️ Anime posters, banners, and visual content
* 🧭 Multiple pages connected through navigation
* ⚡ JavaScript-powered interactions

* **HTML5** — Structure and content
* **CSS3** — Styling, layouts, responsive design, and animations

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Aryan-art-creater/YumeStream.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

Open `Home.html` in your browser.

For development, using the **Live Server** extension in VS Code is recommended.

## 🎨 Design

YumeStream was designed with a focus on creating an immersive anime streaming experience.

The interface uses:

* Dark-themed visual design
* Large anime artwork and banners
* Custom navigation
* Anime cards and content sections
* Interactive buttons and components
* Responsive layouts
* CSS animations and visual effects

The UI was initially designed and experimented with using **Figma** before being implemented with HTML, CSS, and JavaScript.
